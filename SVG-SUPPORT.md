### Text Shaping / International Text

Complex-script shaping (Arabic/Indic), ligatures and combining marks are delegated to the Android text engine.
`direction` is fully supported, `writing-mode` partially, `unicode-bidi` partially (see Font / Text table) —
bidi/shaping coverage follows the platform, not a KSVG-local implementation.

### Explicitly Out of Scope

KSVG is a renderer, not a browser. The following are **None by design**, not planned:
DOM APIs, event handling, focus/keyboard interaction, text selection, scripting (`<script>`),
accessibility/ARIA, `<cursor>`, and HTML navigation behaviors (`<a target>`, `download`, …).
