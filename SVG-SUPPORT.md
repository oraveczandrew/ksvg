## Not Supported

The following SVG elements are explicitly **not** supported:

| Element                                                                                               | Reason                                                                 |
|-------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------|
| [`<foreignObject>`](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/foreignObject) | Requires embedding Android View hierarchies or an HTML renderer.       |
| [`<script>`](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/script)               | Requires JS engine. Out of scope for a performance-sensitive renderer. |
| [`<metadata>`](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/metadata)           | Metadata is ignored. No immediate rendering value.                     |
| [`<font>`](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/font)                   | Deprecated. Modern projects should use `font-family` with OTF/TTF.     |
| [`<font-face>`](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/font-face)         | Deprecated.                                                            |
| [`<glyph>`](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/glyph)                 | Deprecated.                                                            |
| [`<altGlyph>`](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/altGlyph)           | Deprecated in SVG 2.0.                                                 |
| [`<cursor>`](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/cursor)               | Not applicable for general Android drawable rendering.                 |
| [`<color-profile>`](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/color-profile) | Deprecated. Android handles color management at a higher level.        |
